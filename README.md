# 晴天账号铺管理后台

独立管理端仓库：`Zhouzhou198871/admin`

## 构建与部署

- 默认分支：`main`
- GitHub Actions：校验 JavaScript 与静态资源结构
- 生产托管：Vercel 项目 `admin`，由 GitHub `main` 自动触发部署
- 不再发布 GitHub Pages，避免同一管理端出现重复托管入口

## 管理端能力

- 使用晴天号铺原账号密码登录，服务端复核管理员身份
- 运营总览：同时显示当前商城生产数据库指标与旧节点业务指标，明确区分数据来源
- 当前商城订单：直接读取商城生产库的 web_purchases 与 node_orders
- 供应商待核对：查看上游购买结果不确定或卡密待交付的订单；管理员在供应商后台核实后可加密补录交付内容，不会再次提交采购
- 当前商城用户：直接读取商城生产库 users 表，展示注册邮箱、昵称、Telegram 绑定和余额
- 当前商城商品目录：直接读取商城生产库 shop_catalog，显示前台同源图标、CNY/USDT 价格、库存、上架与可购买状态；上游同步目录只读
- 旧业务订单、旧节点用户和旧商品：保留在单独标签页，避免与当前商城账户/订单/商品混淆
- 余额充值：通过现有管理员 API 执行，提交前二次确认
- 机器人管理：读取状态、日志及执行指定服务控制

## API 与数据边界

- API 基址：`https://shop.lynli.me`
- 认证：现有商城登录接口返回的 Bearer token；每个管理 API 都在服务端复核管理员身份
- 数据库：Vercel API 连接 Neon PostgreSQL
- 当前商城商品目录和订单/用户列表直接读取商城 Worker 的受权限保护管理 API，使用与前台相同的 Neon 生产数据库
- 旧节点业务数据仍经签名桥接读取 api.lynli.me，并在后台单独标记
- 商品目录只读；供应商目录、库存与价格以现有同步任务及下单前实时复核为准，不提供虚假的后台改价/上架操作
- 管理后台不提供上游采购下单功能；供应商订单模块仅供核对与人工补发，不会自动重试采购

## 安全边界

- 不在前端保存管理员密钥
- 不直接连接数据库
- 用户列表不返回密码哈希、令牌或其他认证材料
- 管理端不包含供应商采购下单入口；人工补发必须由具备订单管理权限的管理员明确确认上游订单成功
- 机器人操作仅允许三个明确白名单服务
