# 晴天账号铺管理后台

独立管理端仓库：`Zhouzhou198871/admin`

## 构建与部署

- 默认分支：`main`
- GitHub Actions：校验 JavaScript 与静态资源结构
- 生产托管：Vercel 项目 `admin`，由 GitHub `main` 自动触发部署
- 不再发布 GitHub Pages，避免同一管理端出现重复托管入口

## 管理端能力

- 使用晴天号铺原账号密码登录，服务端复核管理员身份
- 运营总览：用户、订单、商品目录统计
- 订单管理：合并查看商城订单与节点订单
- 用户管理：查看邮箱、昵称、Telegram 绑定与余额
- 商品与库存：只读查看商城同步目录和可购买库存
- 余额充值：通过现有管理员 API 执行，提交前二次确认
- 机器人管理：读取状态、日志及执行指定服务控制

## API 与数据边界

- API 基址：`https://shop.lynli.me`
- 认证：现有商城登录接口返回的 Bearer token；每个管理 API 都在服务端复核管理员身份
- 数据库：Vercel API 连接 Neon PostgreSQL
- 采购：继续使用现有“大号商”采购 API，不在管理后台重建采购链路
- 商品目录页面为只读，不直接修改上游商品或采购库存

## 安全边界

- 不在前端保存管理员密钥
- 不直接连接数据库
- 用户列表不返回密码哈希、令牌或其他认证材料
- 不通过管理端发起真实采购或支付
- 机器人操作仅允许三个明确白名单服务
